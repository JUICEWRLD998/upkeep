# Upkeep

**Don't send money home. Send a key.**

A relative abroad keeps dollars in their own Tempo account and gives the parent at home a key with a monthly
limit and a list of payees. The parent pays when she needs to; the chain refuses anything outside the limit.

Built for the Colosseum Crypto World's Fair, Tempo track. Runs on the Tempo Moderato testnet.

Status: LIVE = core library, fee-paying relay, and live chain tests (Phases 0-1). NOT LIVE = UI, payout desk screens. See DECISIONS.md and CLAIMS.md.
